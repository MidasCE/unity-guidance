# Changelog

## [0.1.0] - Unreleased

### Added
- Core rule engine: `GuidanceRule`, `GuidancePrompt`, `GuidanceEvaluator`, built-in `Condition` factory.
- `IGuidanceContext` with a dictionary-backed `GuidanceContext`.
- Progress stores: `InMemoryProgressStore`, `PlayerPrefsProgressStore`.
- `GuidanceTarget` component that resolves UI, 2D and 3D objects to a screen rect, plus `GuidanceTargetRegistry`.
